# 数据来源与分析口径

本项目使用真实公开监测数据，保留原始文件、下载记录、SHA256 和可复现的加工脚本。

已准备 **2024全年、342个活跃地区、31个省级行政区、125,172条城市日记录**。367份小时源文件全部下载成功（含2025年1月1日边界文件），368项原始文件及行政区划文件哈希全部匹配。保留地区均有366条日期记录；33个全年六项日指标均为空的历史地区列已剔除，清单保存在来源元数据。有效PM2.5城市日123,310条；有效派生AQI为120,859条。

## 来源

- 需求书主链接：[天池 dataId=14038](https://tianchi.aliyun.com/dataset/dataDetail?dataId=14038)。准备时旧链接跳转到通用数据集目录，未取得该条目的下载文件。
- 实际下载：[Quotsoft 中国空气质量历史数据](https://quotsoft.net/air/)，下载模板 `https://quotsoft.net/air/data/china_cities_YYYYMMDD.csv`。
- 上游：[中国环境监测总站全国城市空气质量实时发布平台](https://air.cnemc.cn:18007/)。Quotsoft 来源页明确标注这一上游，作为公开历史归档保留城市小时监测值。

本地文件属于公开实时监测历史归档的重算数据，不是天池14038原文件或环保部门审核发布的年度排名。覆盖范围由归档文件中实际城市决定。

## 小时数据到日数据

下载2024全年及2025年1月1日边界文件。小时记录以结束时刻标注，因此一个自然日使用该日1–23时，加上下一日0时，共24个小时观测。

- PM2.5、PM10、SO₂、NO₂、CO：至少20个有效小时值，计算算术平均得到自然日日均值。
- O₃：从同一自然日的小时值计算结束于8–24时的17个8小时滑动窗，每窗至少6个有效小时；按 HJ 663—2013 的日最大8小时有效性条件处理，保留最大值。
- 缺失值、非数值和负值排除；高污染浓度保留，不以统计离群阈值删除污染过程。
- 不直接将任意时刻的滚动24小时值当作自然日日均值，不把实时AQI峰值当作日AQI。
- AQI由有效日浓度按 HJ 633—2012 派生，使用六种污染物的七项日报指标，包含O₃日最大1小时与日最大8小时值；分指数线性插值后向上取整，取最大分指数，并输出中文质量等级。`data_quality` 与 `aqi_reason` 单独保存有效性信息，`quality` 专用于空气质量等级。
- 浓度单位：CO为 mg/m³，其他污染物为 μg/m³。

详细加工统计、确切字段与下载状态见 `data/source.json`。数据准备脚本是 `scripts/prepare_data.py`，执行时会复用已下载的有效缓存。

## 分母、覆盖与异常

年均与月均按有效日值计算，不能把各月均值简单等权平均冒充年均值。年度判断要求不少于324有效日，并且各月不少于27日、2月不少于25日。结果表会分别显示有效日数与年度判断。

城市超标率 = 超标日 ÷ 有效日。省份超标率 = 超标城市日 ÷ 有效城市日。“省内至少1城超标的天数”另列统计，避免把城市日和日历日混在同一个分母中。

缺测天不当作达标天。跳变识别比较相邻日历日，不跨缺测日期拼接；异常标记用于定位值得复核的时段，原始峰值继续参与统计。缺少排放和气象证据时，描述污染变化，不把时序相关性当作已确认的污染成因。

## 现场断网运行

提交包保留处理好的真实日CSV与源文件清单；原始小时缓存留在完整项目的 `data/source-cache/`。现场启动只读本地文件，绘图资源和程序依赖均在本地。若替换教师数据，修改来源说明并重新启动即可按同一工具链分析。
