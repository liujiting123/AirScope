# 核心功能测试证据

验证日期：2026-10-19。目标环境：macOS、Python 3.14、Chrome。模型：通过真实 DeepSeek API 调用 `deepseek-flash`。所有业务统计均使用项目自带的2024年真实城市日数据。

## 自动化测试

运行命令：`python3 -m unittest discover -s tests -v`。

30项定向测试通过，覆盖数据清洗与跨分片去重、有效分母、阈值边界、年/月完整性、AQI插值与分级、多轮城市继承、模型工具参数纠错、工具观察回传、多个分析结果导出、普通问答、API失败与调用轮次上限。模型mock测试执行真实本地统计及文件导出，不依赖真实API计费。

## 界面与执行记录

界面已检查桌面、平板及手机布局。模型工具记录保存在各次 `outputs/<任务ID>/result.json` 的 `trace`，包含工具名、参数、调用ID、耗时和观察结果；`provider` 与 `model` 标明实际模型。`analyses` 保存每次独立分析，`answer` 保存模型最终答复。应用最后生成完整答复报告的动作标记为 `origin=application`。

结构化模型测试使用受控响应替身；以上端到端测试使用真实API，二者分开记录。Windows启动脚本已提供，未在Windows机器实测。
